## 4. 结构与制造总体方案

- **首版方案**：两驱动轮 + 辅助支撑轮 + 可调气隙的底部磁阵列，用垫片调节磁体到钢板的距离。
- **力学判据**：静止抗滑条件 `μ·FN ≥ m·g`； FN 由磁阵列提供，气隙增大则 FN 下降。
- **关键认知**：磁力不是越大越好——磁力同时增加法向力、转向阻力和滚动阻力，直接影响电机选型与电流。因此结构设计 targets 是"气隙可控 + 磁体可靠固定"，而不是堆磁体。
- **不做的**：第 4 周前不做磁轮方案与整机磁阵列对比；未获专项授权不做垂直爬壁。

## 6. 材料、公差与 3D 打印

**材料清单（结构件）**

| 部件   | 候选材料           | 选择理由     | 风险        |
| ---- | -------------- | -------- | --------- |
| 底盘   | PLA / PETG 打印件 | 快速迭代、成本低 | 层间强度、温度变形 |
| 电机座  | PETG / 尼龙      | 需承受堵转反扭矩 | 孔位公差、开裂   |
| 轮子   | TPU / 橡胶胎面     | 影响摩擦系数 μ | 胎面磨损、打滑   |
| 轭铁   | 低碳钢            | 汇集磁路     | 厚度与饱和     |
| 钢板试片 | 多种材质/涂层        | 对照实验基准   | 材料标识不清    |

**公差要点**：电机轴与轮毂配合（过松打滑、过紧装不上）；磁体槽与磁体间隙（需保证不松脱且气隙一致）；左右轮直径差（影响直线度）。

**打印参数记录**：材料 / 层高 / 填充率 / 打印方向 / 后处理，每版打印后填入 `cad/print_log.md`。

## 8. 装配与调试记录

装配顺序：底盘 → 电机座 → 两驱动轮 → 辅助轮 → TB6612 固定 → 磁体与轭铁 → 走线固定。

每次装配后在 `reports/assembly_log.md` 记：

- 打印件编号、实际尺寸与公差偏差
- 磁体固定检查（手推、摇晃确认不松脱）
- 气隙实测值（用塞尺或垫片厚度确认）
- 装配中发现的问题与处理

## 9. 结构问题与复盘

| 现象          | 先查什么（结构侧）               |
| ----------- | ----------------------- |
| 强磁吸住后轮转不动   | 气隙是否过小、胎面摩擦是否过大、轮系是否有干涉 |
| 白板能吸、测试钢板不行 | 钢板材质、板厚、涂层、气隙、磁体固定方式    |
| 走直线偏斜       | 左右轮直径差、轮毂配合松动、底盘变形      |
| 打印件装不上      | 孔位公差、打印方向、热收缩补偿         |
| 磁体松动        | 槽公差、固定工艺、是否需工装          |

每次失败在 `reports/failure_log.md` 写清：现象 → 假设 → 验证方法 → 结论 → 改型动作。
